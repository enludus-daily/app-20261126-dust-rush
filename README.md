# すいこみロボ：充電が切れる前に帰れ / Dust Rush: Robot Vacuum

ロボット掃除機になって、家具の下からわき出すほこりの群れを吸いこむ。ゴミ箱がいっぱいになるたびに強化を 3 つから選び、**充電が切れる前にドックへ帰る**ゲーム（iOS・SwiftUI）。
enludus-daily の 2026-11-26 のアプリ（枠 019・Bundle ID `com.enludus.daily.019`）。題材は監督の昼の企画（daily-ideas #54）：**サバイバー型（群れ＋強化の 3 択）× ロボット掃除機の充電と帰り道**。

## だれの・どう使うか
- すき間の 5 分で、1 回ごとに違う手応えのあるゲームをしたい人。
- 部屋を指でなぞるとロボが進み、ブラシが自動でほこりを吸う。通った床がぴかぴかになる（きれいさ 50/70/85% で星）。
- ゴミ箱がいっぱい → 強化を 3 つから 1 つ（サイドブラシ・速いタイヤ・大きな電池・吸う力・省エネモーター・ふかふかバンパー・磁石）。5 部屋のあいだ続く。
- 「帰りに ○%」と点線がドックへの道。充電が切れる前に帰れば部屋クリア、帰れなければその回はおしまい。**欲張るほど吸えるが、帰れなくなる**のが核。
- 充電が減ると、取りにいけば帰りがぎりぎり（残り 0〜15%）になる所に落とし物が出る。持ち帰ると図鑑に入る。

## 中身
- 30 部屋（10 の間取り × ふつう・おもちゃのブロック・ペットの毛玉）。5 部屋で 1 コース、6 コース。
- 今日の家：日付で決まる 5 部屋（だれでも同じ）。続けた日数・その日のいちばんの点。
- 落とし物図鑑 30 種（それぞれ日英の一言）。共有は絵文字 1 行（🟩🟨🟧⬜🟥）。
- 設定：効果音・振動・練習モード（Pro）・ロボの色と形・遊び方をもう一度・購入を復元。

## 世界観（app-quality-bar）
- **このアプリでは〔フローリングの床〕が〔盤面〕になり、〔ロボが通った筋〕が〔ぴかぴかに光る道〕になる。〔充電ドック〕は下の壁の〔帰り道の目印と灯り〕になる。**
- 真上から見た昼の部屋。床は 4 種の明るい木目（板 22・継ぎ目をずらす）、家具は上から見た形（ソファの座面とひじ掛け・ベッドの枕と布団・本棚の小口・台所の流しとコンロ・洗濯機の窓・浴槽）をミント・ラベンダー・ピーチで。掃除していない床にはうすい灰茶の膜（0.36）、掃除した床は白い光（0.22）。
- ほこりは灰色のふわふわに小さな目（こわくない）、毛玉は紫がかった灰色の毛のかたまり。ロボは白い丸・前のバンパー・回るサイドブラシ・充電の色で光る輪（緑 → 黄 → 赤）。
- 書体は丸ゴシック（`.rounded`）：題字と数字は heavy/bold、本文は medium。ボタンは丸く、下辺だけ濃い 3pt で押せる厚み。
- 前の日までと違う所：11/22 横から見た昼の畑・11/23 夜の水族館・11/24 紫紺と真鍮の天文台・11/25 横から見た朝の段ボールの部屋 → **真上の視点・パステル 3 色・丸ゴシック・床が明るくなっていく**。

## 参考にしたアプリ（ui-reference）
1. サバイバー型の流行り：レベルアップで止まって **3 枚の札から 1 つ**選ぶ場面・上の細い帯・なぞるだけの操作 → ゴミ箱がいっぱいで強化の札がせり上がる・ゴミ箱の帯・なぞって進む。
2. ロボット掃除機のメーカーのアプリの地図：掃除した所が塗られていく部屋・ドックの印・電池の％ → ぴかぴかの筋・ドックへの点線・充電の輪と「帰りに ○%」。

## うれしい・怖い・惜しい（`Tests/DustRushTests.swift` の TensionTests で確かめる）
自動の運転（下から上へしまに往復して掃除）で、30 部屋 × 種を回した結果（2026-11-26、Linux の Swift 6.1 で同じテストを実行）。

| | 決まり | テスト | 結果 |
|---|---|---|---|
| うれしい | 強化を重ねると 1 部屋の吸う量が増える | 強化 0 で平均 50〜60%、強化 4 つ（ブラシ 2・タイヤ 1・電池 1）で 85% 以上 | 56% / 87% |
| 怖い | 充電切れでその回が終わる | ドックを見ずに吸い続け残り 11% で帰ると充電切れ 2〜4 割、残り 30% で帰れば 0 | 29% / 0% |
| 惜しい | 落とし物は高得点だがドックから遠い | 取りにいって帰ったときの残りが 0〜15% の所に出る（30 部屋すべて）。取りにいって帰れた人の残りは 16% 以下 | 0〜15% |

主な数字：ロボの速さ 66・掃除の半径 22（ブラシ 1 段 +6）・充電 100・動くと 1 秒 1.2 減る・毛玉にぶつかると 4 減る・ゴミ箱は 12 から 6 ずつ増える。

## 手応えの表
| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す（なぞり始め・ボタン） | ボタンが 3pt 沈む（下辺の厚みが消える） | selection | ピッ（1320Hz） |
| 1 つ吸う | ほこりが渦を巻いてロボへ寄り、白い輪が広がって消える | 8 個ごとに light | シュッ（続くほど少し高く） |
| まとめて・強化 | ゴミ箱の帯が満ち、3 枚の札が 70ms ずつせり上がる | medium | 3 音の上り → 選ぶとカチッ |
| 失敗（毛玉にぶつかる） | ロボが 0.25 秒止まり、赤い輪が広がる。毛玉ははじかれる | error | ボフッ |
| 残りわずか（30%・15%） | 知らせの札が上から下り、点線が黄 → 赤に | warning | ピピッ |
| 完了（ドックに帰る） | 札がせり上がり、星が 260ms ずつ弾む | success | 充電のポロン 4 音＋星ごとにキン |
| 充電切れ | 輪が灰色に消えて止まる | heavy | 下がるモーター音 |
| 落とし物 | 紫の点線の輪が回り、持つとロボの上に乗る | rigid | キラン |
動きを減らす設定がオンなら、札のせり上がり・星の弾みを止めて値を直接出す。

## デモで見せる流れ（起動引数 `-demo`、英語で録る）
1. ホーム → コース 1 の 1 部屋目。ロボが 3 倍速でしまに走り、床がぴかぴかになっていく。
2. ゴミ箱がいっぱい → 強化を選ぶ → 落とし物が出る。
3. 充電 30% でドックへ帰り、星が弾む。
